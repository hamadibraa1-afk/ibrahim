# واجهة نظام الاقتراحات الرقمي (Angular 17)

التوثيق الكامل للنظام — التشغيل، الأمان، الإشعارات اللحظية، المراجعة المعمّاة، التصعيد،
وقياس الأثر — في [`../README.md`](../README.md).

```bash
npm install
npx ng serve      # http://localhost:4200 — يمرّر /api و/hubs إلى الخادم على 5199 (proxy.conf.json)
npx ng build      # dist/frontend/browser — انسخه إلى wwwroot في الخادم للنشر من مصدر واحد
```
